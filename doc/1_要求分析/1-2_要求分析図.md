# 要求分析図面

## 1. 業務フロー図
```mermaid
flowchart TD
    Start([開始]) --> MainMenu[メインメニュー表示]
    MainMenu --> Select{操作を選択}

    Select -- 1.作成 --> Create[TODO作成フロー]
    Create --> InputInfo[タイトル・内容・期限・優先度入力]
    InputInfo --> Validate{バリデーション}
    Validate -- OK --> Save[タスク保存]
    Validate -- NG --> ShowError[エラー表示]
    ShowError --> InputInfo
    Save --> MainMenu

    Select -- 2.一覧表示/検索 --> List[TODO一覧取得]
    List --> SetFilter[検索・ソート・フィルタ条件適用]
    SetFilter --> Display[一覧表示]
    Display --> MainMenu

    Select -- 3.編集 --> SelectEdit[対象タスクID指定]
    SelectEdit --> EditInput[変更内容入力]
    EditInput --> Update[タスク更新]
    Update --> MainMenu

    Select -- 4.削除 --> SelectDel[対象タスクID指定]
    SelectDel --> ConfirmDel{削除確認}
    ConfirmDel -- Yes --> Delete[タスク削除]
    ConfirmDel -- No --> MainMenu
    Delete --> MainMenu

    Select -- 5.完了済み一括削除 --> BulkDel[完了済みタスク抽出]
    BulkDel --> ConfirmBulk{一括削除確認}
    ConfirmBulk -- Yes --> DeleteAll[対象を全削除]
    ConfirmBulk -- No --> MainMenu
    DeleteAll --> MainMenu

    Select -- 9.終了 --> End([終了])
```
