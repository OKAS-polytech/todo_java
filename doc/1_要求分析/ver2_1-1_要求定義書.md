# 要求定義書 (ver2: ユーザー・グループ管理)

## 1. 概要
本プロジェクトのver2では、個人のTODO管理に加えて、ユーザー管理およびグループ管理機能を導入する。同じグループに所属するユーザー間でのTODO共有を可能にし、チームやコミュニティでのタスク管理を実現する。

## 2. 追加目的
- ユーザーごとのタスク分離と認証機能の提供。
- グループ作成および所属機能による共有範囲の定義。
- 同一グループ内の他ユーザーが作成したTODOの閲覧・共有機能の実現。

## 3. 追加機能要件
### 3.1 ユーザー管理
- **ユーザー登録**: ユーザー名とパスワードを設定してアカウントを作成できる。
- **ログイン/ログアウト**: 作成したアカウントでシステムにログインし、自分専用の領域を確保できる。

### 3.2 グループ管理
- **グループ作成**: 新しいグループを作成し、自分が管理者（所属者）となる。
- **グループ所属**: 既存のグループに他のユーザーを招待または参加させることができる（ver2プロトタイプでは簡易的にグループID指定による参加を想定）。
- **グループ一覧**: 自分が所属しているグループを一覧表示できる。

### 3.3 TODO共有
- **共有TODOの表示**: 所属するグループを指定すると、そのグループに所属する全ユーザーのTODOを一覧表示できる。
- **プライベート/パブリック設定**: TODO作成時に「個人用（自分のみ）」か「グループ共有用」かを選択できる。

## 4. 追加非機能要件
### 4.1 セキュリティ
- パスワードはプレーンテキストではなく、ハッシュ化して保存する（プロトタイプのため簡易的なハッシュ化でも可）。
- ログインしていないユーザーは、いかなるTODOも閲覧・操作できないように制御する。

### 4.2 拡張性
- 将来的な「グループ内での権限管理（閲覧のみ、編集可能など）」を見据えたデータ構造とする。
