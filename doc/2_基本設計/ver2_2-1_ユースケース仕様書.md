# ユースケース仕様書 (ver2: ユーザー・グループ管理)

## UC1: ユーザー登録する
- **概要**: システムを初めて利用するユーザーがアカウントを作成する。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーは登録機能を選択する。
    2. システムはユーザー名、パスワード、パスワード（確認用）の入力を求める。
    3. ユーザーは各項目を入力する。
    4. システムはユーザー名が重複していないか確認する。
    5. システムはパスワードをハッシュ化し、新規ユーザー情報を保存する。
    6. システムは完了メッセージを表示し、ログイン画面へ誘導する。
- **例外シナリオ**:
    - バリデーションエラー：ユーザー名が既に存在する場合、システムはエラーを表示し再入力を求める。
    - 入力不一致：パスワードと確認用パスワードが一致しない場合、エラーを表示する。

## UC2: ログインする
- **概要**: 登録済みユーザーがシステムにアクセスするための認証を行う。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーはユーザー名とパスワードを入力する。
    2. システムは入力された情報に基づき認証を実行する。
    3. システムは認証成功後、ユーザー情報をセッションに保持し、メインメニューを表示する。
- **例外シナリオ**:
    - 認証失敗：ユーザー名が存在しない、またはパスワードが正しくない場合、ログイン画面へ戻す。

## UC3: TODOを個別に管理する
- **概要**: ver1の機能に加え、ログインユーザーごとのタスク管理を行う。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーはTODO一覧表示を選択する。
    2. システムはログインユーザーに紐付くタスクのみを取得して表示する。
    3. ユーザーはタスク作成時、公開範囲（個人用/所属グループ共有用）を選択できる。

## UC4: グループを作成する
- **概要**: ユーザーが新しい共有グループを作成する。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーはグループ作成を選択する。
    2. システムはグループ名の入力を求める。
    3. ユーザーはグループ名を入力する。
    4. システムはグループを保存し、作成したユーザーをグループメンバー（管理者）として自動的に追加する。

## UC5: グループに参加する
- **概要**: 既存のグループに他のユーザーが所属する。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーはグループ参加を選択する。
    2. システムはグループIDの入力を求める。
    3. ユーザーはグループIDを入力する。
    4. システムはグループの存在を確認し、ログインユーザーをメンバーに追加する。

## UC6: グループ内の他ユーザーTODOを閲覧する
- **概要**: 同じグループに所属するユーザー間でTODOを共有する。
- **アクター**: ユーザー
- **メインシナリオ**:
    1. ユーザーは所属するグループの一覧を表示する。
    2. ユーザーは閲覧対象のグループを選択する。
    3. システムは選択されたグループに紐付けられた全ユーザーの「共有設定済みTODO」を一覧表示する。
