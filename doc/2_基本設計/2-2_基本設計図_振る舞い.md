# 基本設計図面（振る舞い）

## 1. アクティビティ図

### UC1: TODOを作成する
```mermaid
flowchart TD
    A[開始] --> B[タイトル入力]
    B --> C[内容入力]
    C --> D[期限入力]
    D --> E[優先度入力]
    E --> F{入力値チェック}
    F -- 不正 --> G[エラー表示]
    G --> B
    F -- 正常 --> H[タスク生成]
    H --> I[リポジトリに保存]
    I --> J[終了]
```

### UC2: TODOを一覧表示する
```mermaid
flowchart TD
    A[開始] --> B[現在の検索・ソート条件取得]
    B --> C[条件に合致するタスクを全件取得]
    C --> D[表示用に整形]
    D --> E[コンソールに出力]
    E --> F[終了]
```

### UC3: TODOを編集する
```mermaid
flowchart TD
    A[開始] --> B[対象ID入力]
    B --> C{タスク存在確認}
    C -- なし --> D[エラー表示]
    D --> B
    C -- あり --> E[変更項目選択]
    E --> F[新しい値を入力]
    F --> G[タスク情報を更新]
    G --> H[リポジトリに保存]
    H --> I[終了]
```

### UC4: TODOを削除する
```mermaid
flowchart TD
    A[開始] --> B[対象ID入力]
    B --> C{タスク存在確認}
    C -- なし --> D[エラー表示]
    D --> B
    C -- あり --> E[削除確認]
    E -- No --> F[終了]
    E -- Yes --> G[リポジトリから削除]
    G --> F
```

### UC5: 条件で検索・整理する
```mermaid
flowchart TD
    A[開始] --> B[条件タイプ選択]
    B --> C{ソート? フィルタ? 検索?}
    C -- ソート --> D[ソート項目指定]
    C -- フィルタ --> E[抽出条件指定]
    C -- 検索 --> F[キーワード入力]
    D --> G[条件をセッションに保持]
    E --> G
    F --> G
    G --> H[一覧表示へ遷移]
    H --> I[終了]
```

### UC6: 完了済みTODOを一括削除する
```mermaid
flowchart TD
    A[開始] --> B[完了済みタスク件数取得]
    B --> C{0件?}
    C -- Yes --> D[メッセージ表示]
    D --> E[終了]
    C -- No --> F[一括削除確認]
    F -- No --> E
    F -- Yes --> G[完了済みをすべて削除]
    G --> E
```

## 2. シーケンス図

### UC1: TODOを作成する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant UC as CreateTaskUseCase
    participant Repo as TaskRepository(Port)
    participant DB as SQLiteAdapter

    User->>UI: 新規作成(各属性入力)
    UI->>UC: execute(CreateCommand)
    UC->>Repo: save(Task)
    Repo->>DB: INSERT
    DB-->>Repo: OK
    Repo-->>UC: Task
    UC-->>UI: TaskDTO
    UI-->>User: 完了メッセージ表示
```

### UC2: TODOを一覧表示する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant UC as GetTasksUseCase
    participant Repo as TaskRepository(Port)
    participant DB as SQLiteAdapter

    User->>UI: 一覧表示要求
    UI->>UC: execute(SearchCriteria)
    UC->>Repo: findAll(Criteria)
    Repo->>DB: SELECT with WHERE/ORDER BY
    DB-->>Repo: ResultSet
    Repo-->>UC: List<Task>
    UC-->>UI: List<TaskDTO>
    UI-->>User: 一覧を整形表示
```

### UC3: TODOを編集する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant UC as UpdateTaskUseCase
    participant Repo as TaskRepository(Port)

    User->>UI: IDと変更内容指定
    UI->>UC: execute(UpdateCommand)
    UC->>Repo: findById(id)
    Repo-->>UC: Task
    UC->>UC: Task属性更新
    UC->>Repo: save(Task)
    Repo-->>UC: OK
    UC-->>UI: Success
    UI-->>User: 更新完了
```

### UC4: TODOを削除する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant UC as DeleteTaskUseCase
    participant Repo as TaskRepository(Port)

    User->>UI: 削除対象ID指定
    UI->>UC: execute(id)
    UC->>Repo: delete(id)
    Repo-->>UC: OK
    UC-->>UI: Success
    UI-->>User: 削除完了
```

### UC5: 条件で検索・整理する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant State as ApplicationState

    User->>UI: 検索条件入力
    UI->>State: updateCriteria(Criteria)
    UI->>User: 条件適用済み一覧を再表示
```

### UC6: 完了済みTODOを一括削除する
```mermaid
sequenceDiagram
    participant User
    participant UI as ConsoleAdapter
    participant UC as DeleteTaskUseCase
    participant Repo as TaskRepository(Port)

    User->>UI: 一括削除実行
    UI->>UC: deleteCompleted()
    UC->>Repo: deleteCompleted()
    Repo-->>UC: DeletedCount
    UC-->>UI: DeletedCount
    UI-->>User: 削除件数を表示
```
