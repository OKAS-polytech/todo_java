# 基本設計図面（構造 - ユースケース別）

## 1. UC1: TODOを作成する
```mermaid
classDiagram
    class ConsoleController {
        +createTask()
    }
    class CreateTaskUseCase <<interface>> {
        +execute(command: CreateCommand)
    }
    class CreateTaskService {
        -repository: TaskRepository
    }
    class TaskRepository <<interface>> {
        +save(task: Task)
    }
    class Task {
        -title
        -content
        -dueDate
        -priority
    }

    ConsoleController --> CreateTaskUseCase
    CreateTaskService ..|> CreateTaskUseCase
    CreateTaskService --> TaskRepository
    CreateTaskService ..> Task : creates
```
