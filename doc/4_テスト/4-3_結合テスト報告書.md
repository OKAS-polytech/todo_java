# 結合テスト報告書

## 1. テスト概要
アプリケーション層（TaskService）とインフラストラクチャ層（SQLiteTaskRepository）の連携を検証する。コンポーネントを結合した状態で、意図した通りにデータベース操作が行われ、ビジネスロジックが成立することを確認する。

## 2. テスト環境
- Java 17
- SQLite 3 (JDBC)
- JUnit 5 / JUnit 6 (JUnit 5.10.0)

## 3. テスト実施結果

| ケースID | テスト項目 | 結果 | 備考 |
|:---|:---|:---|:---|
| IT-01-01 | SQLite保存（サービス経由） | 合格 | TaskService経由でDBに正常に永続化されることを確認 |
| IT-01-02 | SQLite取得（サービス経由） | 合格 | 保存されたデータがDTOとして正しく取得できることを確認 |
| IT-01-03 | 一括削除実行 | 合格 | 完了済みタスクのみが削除されるSQL連携を確認 |
| IT-02-01 | フィルタ連携（優先度） | 合格 | 優先度による絞り込みがリポジトリ層まで正しく伝播することを確認 |
| IT-02-02 | フィルタ連携（ステータス） | 合格 | ステータスによる絞り込みを確認 |

## 4. 判定
合格
