# システムテスト報告書 (ver2: ユーザー・グループ管理)

## 1. テスト概要
CUIインターフェースを介して、ver2で導入した機能（ユーザー登録・ログイン、グループ管理、タスク共有）をエンドツーエンドで検証する。

## 2. テスト環境
- Java 17
- CUI (標準コンソール)
- SQLite (todo_v2.db)

## 3. テスト実施結果

| ケースID | シナリオ | 結果 | 備考 |
|:---|:---|:---|:---|
| ST-V2-01 | ユーザー管理：登録からログインまで | 合格 | 正常に登録・ログインできる |
| ST-V2-02 | タスク独立性：他人のタスク非表示 | 合格 | 自分のタスクのみが表示される |
| ST-V2-03 | グループ管理：作成と参加 | 合格 | ID指定でのグループ参加、一覧表示を確認 |
| ST-V2-04 | グループ共有：タスク閲覧 | 合格 | グループ内の他ユーザーのタスクが表示される |
| ST-V2-05 | 異常系：認証フローの制限 | 合格 | ログイン前にメインメニューへのアクセス不可 |
| ST-V2-06 | 異常系：ログイン失敗時の再入力 | 合格 | メッセージ表示と再入力を確認 |
