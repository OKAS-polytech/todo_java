# システムテスト報告書

## 1. テスト概要
CUIインターフェースを介して、ユーザーが利用する全シナリオを検証する。ユースケースに基づいた操作を行い、期待される画面出力およびデータの整合性を確認する。

## 2. テスト環境
- Java 17
- CUI (標準コンソール)
- SQLite (todo.db)

## 3. テスト実施結果

| ケースID | シナリオ | 結果 | 備考 |
|:---|:---|:---|:---|
| ST-01-01 | 基本CRUDフロー (作成->表示->編集->削除) | 合格 | 一連の流れがエラーなく動作することを確認 |
| ST-02-01 | 日本語対応 (全角文字の保存・表示) | 合格 | 「買い物リスト」などの全角入力が文字化けせず表示される |
| ST-03-01 | ソート機能 (期限順・優先度順) | 合格 | 指定したフィールドで昇順/降順に並び替えられる |
| ST-03-02 | フィルタ機能 (ステータス・優先度) | 合格 | 条件に合致するタスクのみが一覧表示される |
| ST-04-01 | 検索機能 (部分一致) | 合格 | タイトルおよび内容のキーワード検索が動作する |
| ST-05-01 | 完了済み一括削除 | 合格 | 完了済みタスクのみが物理削除される |
| ST-06-01 | 異常系：不正なID指定 | 合格 | 存在しないID指定時に適切なエラーメッセージが表示される |
| ST-06-02 | 異常系：不正な日付形式 | 合格 | 不正入力時に警告が表示され、デフォルト値として処理される |
