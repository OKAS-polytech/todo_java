# テスト計画書 (ver2: ユーザー・グループ管理)

## 1. 目的
本ドキュメントは、ver2で導入された「ユーザー管理」「グループ管理」「共有機能」の品質を保証するためのテスト計画を定義する。

## 2. テスト範囲
- ユーザー登録・ログイン認証。
- グループ作成・参加・一覧表示。
- 同一グループ内でのタスク共有表示。
- ログインユーザーによるタスク操作制限。

## 3. テストフェーズと手法
### 3.1. 結合テスト (Integration Test)
- **対象**: TaskService, AuthService, GroupService ↔ 各SQLiteリポジトリ。
- **検証項目**: 実際のDBを用いた各リポジトリ間のデータ整合性、外部キー制約、認証ロジック。

### 3.2. システムテスト (System Test)
- **対象**: Console UI (ver2)
- **検証項目**: ユーザーごとの独立したタスク表示、グループ参加後の共有、複数ユーザーでの操作想定。

## 4. 完了基準
- 指定したテストケース（ST-V2-01〜ST-V2-05）がすべて合格すること。
