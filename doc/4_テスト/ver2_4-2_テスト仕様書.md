# テスト仕様書 (ver2: ユーザー・グループ管理)

## 1. 結合テストケース (Integration Test ver2)
| ID | テスト項目 | 入力値・条件 | 期待される結果 |
|:---|:---|:---|:---|
| IT-V2-01 | ユーザー登録・ログイン連携 | ユーザー登録 -> そのユーザーでログイン | ログインに成功し、ユーザーIDが返ること |
| IT-V2-02 | グループ作成・所属連携 | グループ作成 -> 所属メンバーとして追加 | そのユーザーの所属グループ一覧に作成したグループが含まれること |
| IT-V2-03 | グループ内タスク共有SQL | ユーザーAがグループ1にタスク登録 -> ユーザーBがグループ1を指定して取得 | ユーザーB側でユーザーAのタスクが取得できること |

## 2. システムテストケース (System Test ver2)
| ID | シナリオ | 手順 | 期待される結果 |
|:---|:---|:---|:---|
| ST-V2-01 | ユーザー管理：登録からログインまで | 1.ユーザー登録(UserA) -> 2.UserAでログイン | メインメニューに「UserA」としてアクセスできること |
| ST-V2-02 | タスク独立性：他人のタスク非表示 | 1.UserAでタスク登録 -> 2.ログアウト -> 3.UserBでログイン -> 4.一覧表示 | UserAのタスクが一覧に表示されないこと |
| ST-V2-03 | グループ管理：作成と参加 | 1.UserAが「Team1」作成 -> 2.UserBがID指定で「Team1」参加 | 両方のユーザーの所属一覧に「Team1」があること |
| ST-V2-04 | グループ共有：タスク閲覧 | 1.UserAが「Team1」宛にTODO作成 -> 2.UserBがグループTODO表示を選択 | UserB側でUserAのTODOが表示されること |
| ST-V2-05 | 異常系：未認証アクセス | 起動直後に直接一覧メニュー（1）を押そうとする | 認証メニュー以外表示されない（CUI仕様上、選択肢が制限されていること） |
| ST-V2-06 | 異常系：ログイン失敗 | 存在しないユーザー名または誤ったパスワードでログイン | 適切なエラーメッセージが表示され、再ログインを求められること |
